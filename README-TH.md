# ชุดเว็บฝึกสอบปริมาตร 10 รูปทรง (แต่ละเว็บแยกอิสระ)

ใน ZIP นี้มีโฟลเดอร์แยก 10 รูปทรง แต่ละโฟลเดอร์เป็นเว็บไซต์ของตัวเอง ไม่มีเมนูรวม ไม่มีปุ่ม Back to study guide และไม่มีลิงก์ข้ามไปเว็บรูปทรงอื่น

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เข้าโฟลเดอร์ของรูปทรงที่ต้องการ เช่น `02-cone`
3. ดับเบิลคลิก `cone.html` เพื่อเปิดเว็บที่เลือก
4. หากต้องการส่งเพียงรูปทรงเดียว ให้ ZIP เฉพาะโฟลเดอร์ของรูปทรงนั้น เพื่อให้ไฟล์ HTML, CSS, JS และ `asset` อยู่ด้วยกัน

## โครงสร้างเว็บไซต์ในทุกโฟลเดอร์
- `*.html` — โครงสร้างเว็บ 4 บล็อก พร้อมฟอร์ม
- `styles.css` — จัดรูปแบบและ Media Query ที่ 576px
- `script.js` — รับเหตุการณ์ `submit` และคำนวณผล
- `asset/` — รูปภาพที่ถูกอ้างอิงผ่าน relative paths

ไฟล์ `CHEAT-SHEET-TH.md` มีสรุปสูตรสำหรับอ่านสอบ แต่อยู่แยกจากเว็บไซต์
